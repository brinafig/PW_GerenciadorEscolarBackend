# Gerenciador Escolar - API (Backend)

Nome: Sabrina Figueiredo

Disciplina: Programação WEB

API desenvolvida para o sistema de gestão escolar, responsável por gerir alunos, disciplinas e matrículas. 

## Tecnologias Utilizadas

* **Node.js** com **Express** (Servidor web)
* **PostgreSQL** (Base de dados relacional)
* **TypeORM** (Mapeamento Objeto-Relacional)
* Alojamento: **Render**
